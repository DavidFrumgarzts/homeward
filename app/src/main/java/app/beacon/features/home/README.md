# features/home/
Home is the map (Find My / Waze style). One file per piece:
- `HomeScreen.kt`: puts the pieces together and handles taps.
- `RedZoneBanner.kt`: Waze-style alert at the top when a red zone is close at night.
- `HomeBottomSheet.kt`: Find My-style sheet with city, pack status, SOS and three round actions.
