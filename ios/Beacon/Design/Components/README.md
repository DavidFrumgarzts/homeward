# Design/Components/
One UI piece per file.
- `PrimaryButton.swift`: the full-width button (blue; red only for SOS and the police call).
- `WhiteCard.swift`: the white rounded card.
- `IconTile.swift`: an icon on a soft colored tile.
- `ProgressBars.swift`: the setup progress bars.
- `InferenceBadge.swift`: "On device" / "Cloud" / "No AI: saved answer" under every answer.
- `HoldButton.swift`: fires only after a 1.5 second hold, with a visible fill (Hold for SOS). VoiceOver: double tap.
- `QuickPickChips.swift`: a wrapping row of pill-shaped choices (and the `WrapLayout` it uses).
- `AskBox.swift`: the white "Ask Beacon" box with the blue square (Home and the chat).
- `NumberedStep.swift`: a step with its number on a light blue circle (answers, "For you, now").
- `BackButton.swift`: the plain back arrow at the top left.
