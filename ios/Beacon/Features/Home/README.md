# Features/Home/
Home is the map (Figma "07 Home").
- `HomeScreen.swift`: puts the pieces together and handles taps; reads location only while Home is open.
- `HomeMap.swift`: Apple Maps with the pack's zones, places and your dot drawn on top by Beacon.
- `RedZoneBanner.swift`: the alert at the top when a red zone is close at a risky hour.
- `HomeSheet.swift`: Ask Beacon box, two ready-made questions, nearest open place to get help, I'm OK, Police, Hold for SOS.
