# Features/
One folder per feature.
| Folder | Feature | Runs |
|---|---|---|
| `Onboarding/` | First launch: the story, welcome, contacts, permissions, get ready | UI |
| `LapaMap/` | The drawn map of Lapa used in the story | drawing |
| `Home/` | Map-first home: Apple Maps with zones and places, red-zone alert, the bottom sheet | UI + offline logic |
| `Ask/` | Ask Beacon chat, answered from the saved pack | hybrid AI, rules as fallback |
| `Sos/` | Write the SOS, open Messages, the active screen | hybrid AI + Messages + Firestore |
| `CheckIn/` | "I'm OK" text to family, location optional | Messages |
